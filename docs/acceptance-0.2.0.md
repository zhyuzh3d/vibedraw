# VibeDraw 0.2.0 交付记录

本轮按“描述 → 绘图 → 预览 → 精绘 → 恢复与导出”重整工作台。提示词放在画布上方，品牌与版本左对齐；工具、工具选项、生成动作分区。右上角菜单提供历史作品、模型配置、软件设置、使用说明与软件信息。

历史以作品为单位自动更新。新建前保存当前作品，继续编辑更新原作，复制产生独立作品。记录包含矢量笔触、提示词、参考图片、原始成图与画面参数；不包含模型密钥。删除需确认，并保留其他作品引用的共享文件。

## 验证

- `node tools/verify.mjs` 通过：20 个运行时源码文件检查、接口适配测试、作品存储与生成队列测试、归档与清单一致性检查。
- CMA-AN00 / Android 11 / Chrome WebView 83 / Hermit 1.10.24 的 DEV revision 10 自检通过 29 项。
- 自检包含绘制、撤销/重做、选择/复制/缩放、生成期间绘图、蒙版透明区域与擦除、图片文件读回、历史恢复/搜索、不重复创建作品、双模型切换、密钥遮罩、实际深色样式、中英文、居中确认与底部面板、无横向溢出、提示词位置、左侧品牌版本及生成操作完整可见。
- 自检完成后恢复原作品和设置，删除自检临时作品；没有执行真实模型请求或截图视觉验收。
