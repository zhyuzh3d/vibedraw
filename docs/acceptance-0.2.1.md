# VibeDraw 0.2.1 交付记录

日期：2026-09-17

## 本轮改进

- 取消触控点击时的强调色焦点轮廓，仅为键盘 Tab 导航保留中性焦点提示。
- 提示词改为画布上方单行输入，移除可见“画面描述”标签，右侧改为显式保存按钮。
- 作品标题栏收敛为重命名、保存状态和作品设置；作品设置按文件保存重绘强度、随机种子、笔刷等待、继续绘制和叠加透明度。
- 画布操作顺序调整为调色、撤销、重做、清空，清空图标改为垃圾桶。
- 新增非破坏性调色：亮度、对比度、饱和度、色相、梦幻辉光和清晰度，预览与导出共用同一效果逻辑。
- 以应用内紧凑 RGB/色板面板替代系统颜色选择器；画笔色和底色使用圆形实色按钮。
- 所有滑杆统一为 20 px 圆形触点，弹窗、按钮、字段字号与间距统一。
